# ConectaDoações | Projeto PROO 2026.2 — BSI

O ConectaDoações é uma plataforma digital que conecta diretamente pessoas que necessitam
receber materiais (beneficiários) a pessoas que desejam disponibilizá-los (doadores). A proposta tem
como foco inicial os materiais escolares, com estrutura que permita expandir o catálogo para outras
categorias de doações.
